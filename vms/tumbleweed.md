# openSUSE Tumbleweed

| Campo | Valore |
| --- | --- |
| VM | tumbleweed |
| Installer | AutoYaST via ISO `OEMDRV` |
| Desktop | GNOME |
| Disco | 40G qcow2 virtio |
| UEFI | si |
| Shared | virtiofs tag `shared` su `/mnt/shared` |

Uso:

```bash
make tumbleweed
```

La ISO usata e' `openSUSE-Tumbleweed-DVD-x86_64-Current.iso`.
